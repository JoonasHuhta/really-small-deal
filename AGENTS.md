# Working on Really Small Deal

A short humorous browser + Android game about rejection sensitivity. The player is the overprotective shadow **Ekskyysmi**; the human is "HUMAN". Game text is English. Docs are Finnish.

## How the code is built
- Edit only `src/NN-name.js`. **Never edit `assets/game.js`**: it is generated by `node tools/build.cjs`.
- `npm test` must pass before every commit: `tests/story.test.cjs` plays every route, and `tests/moments.test.cjs` plays every moment on three choice paths with drawing.
- `node tools/build.cjs --check` fails if `assets/game.js` is stale.
- `python tools/audit_layout.py [state ...]` checks the layout at five phone sizes and saves screenshots to `tools/audit-shots/` (needs Playwright).
- Settings that change pacing (0.99.50): *Slow reality* (`slowReality`, only lengthens the respond-correctly window) and *Auto: reading pace* (`autoRead`, `stepAutoRead` in `src/60-update.js`). Auto moves only a shown line on, or a `{still}` beat, after `max(1.4, words/200*60 + 0.9)` s; every other WAIT state (choice, hold, view, stretch, qte, toss, lamp, fight) and every overlay still waits for the player. `tests/story.test.cjs` §18 plays a week on ticks alone with Auto on.
- The receipt picture (0.99.52, `shareReceipt` in `src/35-inside.js`): in a browser it shares or downloads the PNG; in the app it writes the PNG to the cache with `Capacitor.Plugins.Filesystem` and opens Android's share sheet with `Capacitor.Plugins.Share`. Any failure copies the text; closing the sheet only resets the label. The plugins are `@capacitor/filesystem` and `@capacitor/share` (exact versions in package.json); `tools/android-patch.cjs` keeps the FileProvider and cache path, `tools/android-check.cjs` checks them. See ANDROID.md.
- The respond-correctly window opens with a 0.35 s startle (`QTE_FREEZE`, 0.99.55): presses and taps do not count yet, so a double press on the line before cannot fail it unseen. The clock starts after it; Enter after it is still wrong. Keep it.
- *Skip seen* (0.99.51) was removed in 0.99.54 at Joonas's request; do not bring it back. Old saves may hold `ekskyysmi.seen`, which the game deletes.
- The bottom bar on phones (0.99.54): under `@media(max-height:440px)` the immersive bar uses smaller type (line 13 px, name 11 px, choices 12 px, times the text step), tighter lines and a narrower Continue. Joonas's phone shows the page at about 500 × 285 CSS px (text zoom), where a 90-character line was 49 % of the screen; it is 27 % now. Check new bar UI at 507 × 285 as well as the audit sizes.
- `node tools/transcript.cjs` (or `npm run transcript`) prints what a player reads: every line, every choice offered, outside views and hands-on steps. `--pick 0|1|2|rotate`, `--day A|B|C`, `--lab <id>` for one Moment, `--out file`. Read a changed scene on at least two routes before committing.
- Any new `G.` field that draws something must be reset in `scene()` (`src/31-story-week.js`), or it leaks into the next scene.
- Languages (0.89, rebuilt 0.99.39): every line, choice, card, outside view, menu, overlay and receipt goes through `tr()` (`src/15-fi.js`), and **the canvas translates by itself**: `ctx.fillText`, `strokeText` and `measureText` pass through `trQ()` (`i18nCtx` in `src/00-core.js`), so a sign or caption you draw is translatable and measured in the language shown. HTML you build still needs `tr('…')` around each whole sentence. One dictionary per language in `DICT` (`DICT.fi` = `FI`, `src/16-fi-monday.js`); number formats and quotation marks in `LOC`. A string with numbers translates from a `{n}` entry (`'DELETED · TAKE {n}'`). Text that must fit a box: give `fillText` its max width (4th argument) or use `wrapText(s,maxW)`. `npm run strings` writes every string a player can see to `i18n/strings.tsv`; `node tools/strings.cjs fi` lists what Finnish still lacks. `tests/i18n.test.cjs` plays the week and every Moment in the pseudo-language (`LANG='xx'`, offered in testing mode) and fails on any English that skipped translation; `tests/fi.test.cjs` fails if Monday shows English in Finnish. Do not name a local variable `tr`. **Translations were on hold until the English was locked (Joonas 22.11.); on 27.11. Joonas said translating starts soon.** See KAANNOS.md.
- Android: `npm run android:sync`, then `android\gradlew.bat assembleDebug`. The `android/` folder is not in git; native changes go through `tools/android-patch.cjs`.

## Script engine in one minute
- A scene is an array of steps: `['S','line']`, `['S','line',{look:'squint'|'pleased'|'stunned'|'soft'|'up'|'edge',loud:1,quiet:1}]`, `aside([...])`, `{wait:1.2}`, `{choice:[{t:'…',then:[…]}]}` (the picked option is spoken first as a bubble; `hush:1` keeps it silent, `echo:false` skips the echo when the option's own next line asks it), `{hold:{kind,secs,text}}`, `{toss:{…}}`, `outside({title,dur,cap})`, `set({mood,s,…})`, `addTic(text,x,y,{life})`, `lensPeek(at,tag)`.
- A step that expands into several steps must be a **function returning an array**.
- Speakers: S Ekskyysmi, H human, A Sanna, B Eero, R Riitta, P phone, N narrator, Z/Y/W other people's shadows.
- Story order: `src/33-moments.js` (`AFTER`). Moments are registered in `LABS` (`src/50-lab.js`).
- **Testing mode** (0.99.32): Settings › *Unlock all (testing)* (`TESTING`, localStorage `ekskyysmi.test`) opens every chapter and every scene. The APK cannot take `?lab`, so this is how scenes are reached on a phone.
- CAPITALS in a line are emphasis and are drawn as such. Use them like a writer, not a shouter.
- **New Moments being tried** (0.99.22–): one file each, `src/59-<name>.js`. Register the scene in `LABS`, add its id to `TRYING` and a one-line situation to `SITUATION` (`src/50-lab.js`); it then shows under *New. Being tried* in the Moments menu, outside the story. A Moment that needs its own room, a per-frame step or a front layer registers it in `SETS`, `MSTEP` or `MFRONT` (`src/00-core.js`) instead of being wired into the engine. A new hold kind needs its own branch in `holdText`, `holdStep` and `finishHold` (an unknown kind falls through to the comforting pose). A full-screen picture that belongs to the inside version (the meadow in *Snow indoors.*) is `G.out={anim:'…',inside:true}` with its own `drawOutside` branch: the label stays THE INSIDE VERSION and the lines play in the panel; clear `G.out` before the real `outside(…)`.

## Rules of the writing
- Ekskyysmi is always wrong about scale and often right about the observation. Bureaucratic, sincere, never cruel.
- No advice, no therapy language, no diagnosis words. "It isn't advice."
- A habit is a preference, never a compulsion played for laughs.
- Alcohol is never the fix. In the bar evening it is tiredness that drops the filter; the human drinks ginger beer.
- Do not add, move or cut moments without Joonas. Before changing a line, check which threads in `TARINAKARTTA.md` §5 run through it. One structural change per version.
- The Scenario lab is a development tool only. The finished game is scene-based and runs in chronological order (think *Night in the Woods*). Do not build features around the lab.
- The default face is the joke; a special look lasts one line.
- New content is a new trigger in the same formula (trigger, reading, choice with a cost, outside version, receipt). No new meters on screen.

## When you finish a step
Update the version note in `README.md` and the map in `TARINAKARTTA.md`, bump `package.json`, run the tests, and say plainly what was not verified on a real device.
