# Working on Really Small Deal

A short humorous browser + Android game about rejection sensitivity. The player is the overprotective shadow **Ekskyysmi**; the human is "HUMAN". Game text is English. Docs are Finnish.

## Read first (updated 21.11.2026, version 0.77)
The code is always the truth. Of the documents, these are current:
1. **`TARINAKARTTA.md`: the story map.** Order, cards, clocks, lengths, the threads that connect scenes (§5), fixed and open holes (§6), characters (§7), decisions (§8). Refer to scenes by its numbers (*#9 An ordinary evening*). If the order changes, the map changes in the same commit (a test checks it).
2. **`EKSKYYSMI.md`: the character bible.** Origin, relation to RSD, symbols, rules (§7), research (§9).
3. `VISIO.md` (pillars) and `OUTOUDET.md` (quirks and the "no mockery" rule).

Older plans are history and partly out of date: `TYOSUUNNITELMA.md`, `CODEX_JATKO.md`, `SUUNTA.md`, `TOINEN_NAYTOS.md`, `KASIKIRJOITUS.md` (its 0.26 structure table), `SEURAAVAKSI.md`. Read them for ideas, not for the current order.

## How the code is built
- Edit only `src/NN-name.js`. **Never edit `assets/game.js`**: it is generated by `node tools/build.cjs`.
- `npm test` must pass before every commit: `tests/story.test.cjs` plays every route, and `tests/moments.test.cjs` plays every moment on three choice paths with drawing.
- `node tools/build.cjs --check` fails if `assets/game.js` is stale.
- `python tools/audit_layout.py [state ...]` checks the layout at five phone sizes and saves screenshots to `tools/audit-shots/` (needs Playwright).
- Any new `G.` field that draws something must be reset in `scene()` (`src/31-story-week.js`), or it leaks into the next scene.
- Languages (0.89): script lines, choices, names, outside views, hint and receipt rows already go through `tr()` (`src/15-fi.js`). Text you draw yourself with `fillText` or build into HTML must be wrapped in `tr('…')`, as a whole sentence (use `{a}` placeholders for numbers). Finnish is in `src/16-fi-monday.js`; `tests/fi.test.cjs` fails if Monday shows English in Finnish mode. Do not name a local variable `tr`.
- Android: `npm run android:sync`, then `android\gradlew.bat assembleDebug`. The `android/` folder is not in git; native changes go through `tools/android-patch.cjs`.

## Script engine in one minute
- A scene is an array of steps: `['S','line']`, `['S','line',{look:'squint'|'pleased'|'stunned'|'soft'|'up',loud:1,quiet:1}]`, `aside([...])`, `{wait:1.2}`, `{choice:[{t:'…',then:[…]}]}`, `{hold:{kind,secs,text}}`, `{toss:{…}}`, `outside({title,dur,cap})`, `set({mood,s,…})`, `addTic(text,x,y,{life})`, `lensPeek(at,tag)`.
- A step that expands into several steps must be a **function returning an array**.
- Speakers: S Ekskyysmi, H human, A Sanna, B Eero, R Riitta, P phone, N narrator, Z/Y/W other people's shadows.
- Story order: `src/33-moments.js` (`AFTER`). Moments are registered in `LABS` (`src/50-lab.js`).
- CAPITALS in a line are emphasis and are drawn as such. Use them like a writer, not a shouter.

## Rules of the writing
- Ekskyysmi is always wrong about scale and often right about the observation. Bureaucratic, sincere, never cruel.
- No advice, no therapy language, no diagnosis words. "It isn't advice."
- A habit is a preference, never a compulsion played for laughs.
- Alcohol is never the fix. In the bar evening it is tiredness that drops the filter; the human drinks ginger beer.
- Do not add, move or cut moments without Joonas. Before changing a line, check which threads in `TARINAKARTTA.md` §5 run through it. One structural change per version.
- The Scenario lab is a development tool only. The finished game is scene-based and runs in chronological order (think *Night in the Woods*). Do not build features around the lab.
- The default face is the joke; a special look lasts one line.
- New content is a new trigger in the same formula (trigger, reading, choice with a cost, outside version, receipt). No new meters on screen.

## When you finish a step
Update the version note in `README.md` and the map in `TARINAKARTTA.md`, bump `package.json`, run the tests, and say plainly what was not verified on a real device.
